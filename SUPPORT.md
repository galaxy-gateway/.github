# Support

- **Bug?** Open an issue in the repo where it happens.
- **Question or idea?** Start a discussion in that repo (or the org discussions if you are not sure where it belongs).
- **Security problem?** Do not open a public issue. See [SECURITY.md](SECURITY.md).
- **Not sure which repo?** The [Galaxy Gateway hub](https://github.com/galaxy-gateway/galaxy-gateway) is the index of every project.
- **Want to work with us?** Start a conversation at https://galaxygateway.dev/transmit.

These are volunteer-run projects. We read everything, but we cannot promise response times.
